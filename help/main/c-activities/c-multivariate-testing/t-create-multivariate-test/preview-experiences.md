# 預覽[!UICONTROL 多變數測試]的體驗 {#preview-mvt-experiences}

>[!BEGINSHADEBOX]

**在此頁面上：**&#x200B;瞭解如何預覽&#x200B;**[!UICONTROL 視覺化體驗撰寫器]**&#x200B;中&#x200B;**[!UICONTROL 多變數測試]**&#x200B;的每個體驗，以及如何排除或包含體驗。

>[!ENDSHADEBOX]

[!DNL Adobe Target]中的&#x200B;**[!UICONTROL 多變數測試]** (MVT)會比較一個頁面上的多個體驗，因此預覽每個體驗的頁面會很有幫助。 預覽會顯示選件在每個體驗中的結合方式，讓您決定在測試上線之前是否排除體驗。

1. 在&#x200B;**[!UICONTROL 視覺化體驗撰寫器]** (VEC)中，按一下&#x200B;**[!UICONTROL 預覽]**，然後按一下&#x200B;**[!UICONTROL 顯示體驗]**&#x200B;圖示（![顯示體驗圖示](/help/main/assets/icons/WebPages.svg)）以顯示左側框架中的所有體驗清單。

   ![變更影像選件功能表](../assets/multivariate-5.png)

1. 按一下清單中的特定體驗來檢視該體驗。

1. （選擇性）若要排除或包含體驗，請按一下&#x200B;**[!UICONTROL 管理內容]**&#x200B;圖示（![管理內容圖示](/help/main/assets/icons/Experience.svg)）以顯示&#x200B;**[!UICONTROL 管理內容]**&#x200B;對話方塊。

1. 您可能會選擇排除顯示發生衝突變數的體驗，或是審美觀點上不平衡的體驗。 然後執行下列任一項作業：

   * 若要排除一個體驗，請按一下體驗旁的&#x200B;**[!UICONTROL 更多動作]**&#x200B;圖示（ ![更多動作圖示](/help/main/assets/icons/MoreSmallList.svg) ），然後按一下&#x200B;**[!UICONTROL 排除]**。
   * 若要排除多個體驗，請選取體驗的核取方塊，然後按一下[排除]。****
   * 若要包含已排除的多個體驗，請選取體驗的核取方塊，然後按一下&#x200B;**[!UICONTROL 包含]**。

>[!NOTE]
>
>建立多變數測試時，您可以從測試排除超過10%的體驗，但前提是您認可之後必須使用離線報表進行分析的警告。
