# 測試摘要（[!UICONTROL 多變數測試]） {#mvt-test-summary}

>[!BEGINSHADEBOX]

**在此頁面上：**&#x200B;瞭解&#x200B;**[!UICONTROL 多變數測試]**&#x200B;的測試摘要會顯示哪些內容，以便在繼續之前檢閱組態。

>[!ENDSHADEBOX]

**[!UICONTROL 鎖定目標]**&#x200B;頁面提供[!DNL Adobe Target] **[!UICONTROL 多變數測試]**&#x200B;的視覺化概觀。 檢閱此摘要可讓您在設定目標與設定之前確認測試的設定。

![測試摘要對話方塊](/help/main/c-activities/c-multivariate-testing/t-create-multivariate-test/assets/summary-new.png)

測試摘要顯示:

* 測試名稱。
* URL。
* 對象。 按一下對象，從可用對象清單中選取不同的對象。
* 演演算法。 唯一可用的演演算法是&#x200B;**[!UICONTROL 全階乘]**。 演演算法名稱僅供參考，供您瞭解所使用的演演算法。
* 包括和排除體驗的數量。

當您對測試組態感到滿意時，請按一下&#x200B;**[!UICONTROL [下一步]]**。 **[!UICONTROL 目標與設定]**&#x200B;頁面隨即開啟。
