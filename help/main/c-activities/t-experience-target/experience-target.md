# 開始使用[!UICONTROL 體驗鎖定目標] {#get-started-xt}

>[!BEGINSHADEBOX]

**在此頁面上：**&#x200B;瞭解什麼是&#x200B;**[!UICONTROL 體驗鎖定目標]**、它如何適合個人化，以及案例如何鎖定不同體驗的不同對象。

>[!ENDSHADEBOX]

[!UICONTROL 體驗鎖定目標] (XT)會根據一組行銷人員定義的規則和條件將內容提供給特定對象。 對於定義將特定體驗或內容鎖定在特定對象的規則（包括[地理定位](/help/main/c-target/c-audiences/c-target-rules/geo.md)）非常有用。 您可以在單一活動中定義數個規則，以將不同的內容變數傳送至不同的對象。

訪客檢視您的網站時，[!UICONTROL 體驗鎖定目標]會評估這些訪客，以判斷他們是否符合您設定的條件。 如果他們符合條件，他們會進入活動，並且針對合格對象設計的體驗會顯示。

[!UICONTROL 體驗鎖定目標]是個人化世界的第一步，通常會從A/B測試開始。 行銷人員執行A/B測試，並透過使用報表受眾，發現不同體驗會與不同受眾產生共鳴。 [!UICONTROL 體驗鎖定目標]可讓行銷人員輕鬆使用該探索，並切換為長期鎖定目標內容，以鎖定這些不同對象區段。

## 案例：從A/B測試到體驗鎖定目標 {#xt-scenario}

假設您的網站以戶外裝置為特色。 您的A/B測試報表顯示您有三個體驗，能讓不同的受眾產生迴響。 若要套用此探索，您想要在首頁上顯示不同的主圖影像，根據訪客的位置或興趣來吸引每個對象。 您想要向來自紐澤西的訪客顯示健行影像、向來自夏威夷的訪客顯示衝浪影像，並向喜歡騎腳踏車的受眾顯示第三個影像。

[!UICONTROL 體驗鎖定目標]活動可讓您以各自不同的主圖影像鎖定這三個對象。 下列影片說明如何使用[!UICONTROL 體驗鎖定目標]，將A/B測試提升到下一個層級。 它會顯示如何：

* 使用三步驟引導式工作流程設定[!UICONTROL 體驗鎖定目標]活動。
* 您可以建立以這兩個州為目標的體驗，以及以腳踏車愛好者為目標的第三個體驗，藉此為不同地理區域的受眾提供特定位置的內容。
* 重新排序這三個體驗，以確保將正確的內容傳送給正確的對象。
