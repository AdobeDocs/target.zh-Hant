# 要求存取權 {#request-access}

對旗標的存取在團隊層級進行管理。 若要使用旗標，您需要將自己新增到具有適當角色的團隊中。

## 先決條件 {#prerequisites}

在請求存取權之前，請確認下列事項：

* 您知道要加入哪個團隊。 請洽詢您的產品或工程負責人，以識別您的團隊及其管理員。
* 您知道您需要存取哪個沙箱。

## 要求存取權 {#request-steps}

如需存取要求，請洽詢您的Adobe代表。

## 可用的角色 {#roles}

指派給您的角色會決定您可在主控台中執行的動作。 如果您不確定要請求哪個角色，請聯絡管理員。

| 角色 | 說明 |
| --- | --- |
| **管理** | 主控台的完整存取權。 可以管理應用程式。 |
| **產品發行擁有者** | 可以建立和管理功能標幟和功能群組，以及將功能發行給外部使用者。 |

## 在授與存取權之後 {#after-access}

您的請求獲得核准後，請在Adobe Target中開啟標幟，並確認您的應用程式可供檢視。 如需後續步驟，請參閱Adobe Target中的[存取旗標](log-in-to-the-console.md)。

## 需要協助嗎？ {#need-help}

如果您不確定要加入哪個團隊，或您的專案尚無團隊，請聯絡貴組織的「旗標」管理員。
