# 建立您的第一個功能標幟 {#create-feature-flag}

## 先決條件 {#prerequisites}

在建立功能標幟之前，請完成下列工作：

* 您可以存取旗標主控台 — 請參閱[登入主控台](../console/log-in-to-the-console.md)
* 您的應用程式已上線 — 請參閱[將應用程式上線](../applications/onboard-your-application.md)
* 您有&#x200B;**產品發行擁有者**&#x200B;角色

## 步驟1：建立功能標幟 {#create}

若要建立新功能標幟，請遵循主控台中的下列步驟：

1. 登入&#x200B;**旗標主控台**，前往左側面板，然後選取&#x200B;**功能旗標**。
1. 從&#x200B;**應用程式**&#x200B;下拉式清單中選取您的應用程式。
1. 選取&#x200B;**新功能旗標**。
1. 填寫表單欄位：

   | 欄位 | 說明 |
   | --- | --- |
   | **名稱** | 功能標幟的顯示標籤。 未用於程式碼。 **Name**&#x200B;僅是顯示標籤，不會用於程式碼中；兩者是獨立的（Name不會轉換為金鑰）。 |
   | **索引鍵** * | 在您的程式碼中用來評估標幟的識別碼。 建立後即無法變更。 **Key**&#x200B;是程式碼中使用的識別碼，建立後即無法變更。 索引鍵&#x200B;**不能包含空格**&#x200B;且有&#x200B;**區分大小寫**，在[索引鍵]欄位中輸入空格會產生錯誤： _「功能索引鍵的值無效。」_ |
   | **說明** | 說明檔案用途選用。 |
   | **中繼資料** | 選填。 最多1,024個字元。 此欄位用於與標幟關聯的任何其他中繼資料。 |
   | **標記** | 用於說明檔案的選用標籤。 |
   | **身分** * | 此旗標是依據身分評估（例如ECID）。 這是功能要求中傳遞的身分。 |
   | **轉出百分比** | 提供此功能的已定義對象百分比。 預設為100%。 請參閱[設定逐步推出的功能](set-feature-gradual-rollout.md)。 |

   標有 * 的欄位為必填欄位。

>[!IMPORTANT]
>
>您在此處選取的身分識別，必須符合應用程式在擷取功能標幟時傳遞給SDK的身分識別。 如果兩者不符，SDK會找不到預期的身分，並退回給臨時的、隨機產生的ID以指派變體。 旗標評估繼續運作，沒有顯示錯誤，使用者仍會收到變體。
>
>然而，使用暫時ID時，使用者可能會在每次應用程式重新啟動時收到不同的變體，而且無法保證同一人在各裝置間有一致的變體。

1. 選擇性地新增對象條件（請參閱步驟2）。
1. 儲存您的功能標幟設定。

## 步驟2：新增對象條件 {#audience}

對象條件可控制哪些使用者會看到此功能。 您可以鎖定具有&#x200B;**內容屬性**&#x200B;的使用者 — 您的網站或應用程式在功能要求中傳送的值（例如`locale`或`platform`）。 將它們與&#x200B;**AND**、**OR**&#x200B;和&#x200B;**NOT**&#x200B;合併。 請參閱[在對象規則中使用內容](../audience/using-context-in-audience-rules.md)。

若要新增對象條件，請在建立或編輯功能標幟時前往&#x200B;**對象**&#x200B;標籤。
