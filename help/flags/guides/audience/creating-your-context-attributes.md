# 建立您的內容屬性 {#creating-your-context-attributes}

內容屬性是描述使用者、工作階段或應用程式內容（例如訂閱層、應用程式版本或區域）的自訂資料欄位。 使用內容屬性來定義功能標幟的對象條件。

前後關聯群組會將相關前後關聯屬性組織成邏輯階層。 使用前後關聯群組可讓屬性在功能組態期間更容易找到和管理。

| 術語 | 說明 | 使用位置 |
| --- | --- | --- |
| **內容屬性** | 具有資料型別和選擇性預先定義值的已命名欄位。 | 對象條件、功能設定 |
| **內容群組** | 組織相關內容屬性的類別。 | 建立特徵時的前後關聯選取 |
| **UI標籤** | 顯示在使用者介面中的顯示名稱。 | 對象條件和管理頁面 |
| **識別碼** | 唯一的技術識別碼。 | 應用程式要求 |
| **預先定義的值** | 允許值的選用清單及顯示標籤。 | 下拉式清單和對象規則產生器 |

## 先決條件 {#prerequisites}

在管理前後關聯屬性和前後關聯群組之前，請先完成下列作業：

* 您可以在正確的沙箱中存取&#x200B;**旗標主控台**。
* 您擁有建立和管理內容屬性與內容群組所需的&#x200B;**管理員**&#x200B;角色。

## 導覽至內容屬性 {#navigate}

1. 登入&#x200B;**旗標主控台**。
1. 在左側導覽的&#x200B;**儀表板**&#x200B;下，選取&#x200B;**內容屬性**。

您現在位於&#x200B;**內容屬性**&#x200B;頁面。 您可以在此頁面建立前後關聯群組與前後關聯屬性。

## 建立內容群組 {#create-group}

每個內容屬性都必須屬於一個群組。

1. 在左側導覽的&#x200B;**儀表板**&#x200B;下，選取&#x200B;**內容屬性**。
1. 在&#x200B;**我的內容屬性**&#x200B;索引標籤上，選取&#x200B;**新增群組**。
1. 填寫必要欄位。
1. 選取&#x200B;**建立**。

### 群組欄位 {#group-fields}

| 欄位 | 說明 |
| --- | --- |
| **群組名稱** | 輸入群組的唯一名稱。 |
| **建立**&#x200B;的子群組 | 選取父群組以組織階層。 您也可以在建立屬性時建立群組。 |

## 建立內容屬性 {#create-attribute}

1. 在&#x200B;**我的內容屬性**&#x200B;標籤上，選取&#x200B;**新增內容屬性**。
1. 填寫必要欄位。
1. 選取&#x200B;**提交**。

### 屬性欄位 {#attribute-fields}

| 欄位 | 說明 |
| --- | --- |
| **UI標籤** | 輸入對象條件中使用的顯示名稱。 |
| **識別碼** | 輸入用於應用程式要求的唯一技術識別碼。 |
| **內容群組** | 選取群組或建立新的內嵌群組。 |
| **資料型別** | 選取與應用程式傳送的資料相符的型別。 |

| 資料類型 | 範例 |
| --- | --- |
| STRING | `gold` |
| 整數 | `42` |
| 布林值 | `true` |
| 小數 | `9.99` |
| 日期 | `2026-07-17` |
| 版本 | `1.2.0` |

### 預先定義的值（選擇性） {#predefined-values}

使用預先定義的值，將屬性限製為固定的值集。 選取&#x200B;**新增預先定義的值**。

| 欄位 | 說明 |
| --- | --- |
| **UI標籤** | 輸入顯示名稱。 |
| **值** | 輸入應用程式傳送的技術值。 |

選取&#x200B;**儲存**&#x200B;以套用您的變更。

## 疑難排解 {#troubleshooting}

| 問題 | 解決方法 |
| --- | --- |
| **建立**&#x200B;已停用 | 完成&#x200B;**群組名稱**&#x200B;和&#x200B;**建立**&#x200B;的子群組。 |
| 無法提交屬性 | 完成&#x200B;**識別碼**&#x200B;和&#x200B;**內容群組**。 |
| 群組在下拉式清單中不可見 | 重新整理頁面，或從屬性表單內嵌建立群組。 |
| 預先定義的值未儲存 | 在送出屬性之前，在強制回應視窗中選取&#x200B;**儲存**。 |
